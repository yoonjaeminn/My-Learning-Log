# [중간 보고서] SECOM 데이터를 활용한 불량 예측 및 원인 분석
  
**분석 환경:** Kaggle Notebook (Python 3.10)  
**핵심 라이브러리:** `Scikit-learn`, `Imbalanced-learn (SMOTE)`, `Joblib`, `Pandas`

---

## 1. 프로젝트 개요 (Introduction)

### 1.1 배경 및 목적
반도체 제조 공정은 수천 개의 변수가 복합적으로 작용하며, 불량 데이터가 정상 데이터에 비해 극도로 적은(6.6%) 극심한 데이터 불균형(Class Imbalance) 특성을 가집니다. 본 프로젝트는 이러한 환경에서 단순 정확도의 함정을 극복하고, 실제 불량을 잡아내는 재현율(Recall)을 극대화하는 모델을 구축하는 데 목적이 있습니다.

### 1.2 핵심 성과
* **불량 검거율(Recall):** 초기 0% → 현재 81%
* **전체 분류 정확도(Accuracy):** 현재 91%
* **핵심 센서 규명:** 불량 유발 주범 센서(59, 103, 33번)로 특정

---

## 2. 데이터 분석 프로세스 (Methodology)

### 2.1 피처 엔지니어링 및 선택
* **Feature Selection:** Mutual Information 통계를 활용하여 500여 개의 센서 중 영향력이 큰 **상위 50개 변수**를 선별.
* **Outlier Flag:** 3-sigma 임계값을 초과하는 수치에 대해 별도의 가중치 피처를 생성하여 공정 불안정성 반영.

### 2.2 불균형 데이터 대응 (SMOTE)
* 정상 데이터에 매몰되지 않도록 SMOTE 기법을 적용하여 증폭 학습함.

### 2.3 알고리즘 및 하이퍼파라미터
* **Model:** Random Forest Classifier (n_estimators=300)
* **Optimization:** Decision Threshold를 기본값 0.5에서 0.23으로 하향 조정하여 탐지 감도 극대화.

---

## 3. 모델 성능 평가 (Evaluation)

본 모델은 불량이 고객사로 유출되는 리스크 비용을 최소화하기 위해 Recall(재현율)과 F1-Score를 최우선 지표로 삼았습니다.

| 지표 (Metric) | 수치 (Value) | 의미 및 해석 |
| :--- | :--- | :--- |
| **Accuracy** | **91%** | 전체 샘플 중 정상/불량을 올바르게 분류한 비율 |
| **Recall** | **81%** | 실제 불량 21개 중 17개를 검거 (유출 방지 핵심 지표) |
| **Precision** | **16%** | 불량이라 예측한 것 중 실제 불량 비율 (공정 마진 설정 결과) |
| **F1-Score** | **0.27** | 정밀도와 재현율의 조화 평균 (최적 균형점 0.23 지점) |

> **[Note]** 16%의 정밀도는 재현율 80% 이상을 유지하기 위한 의도적인 'Trade-off' 결과입니다. 이는 전수 조사 대비 검사 공정 부하를 약 70% 감소시키면서 대부분의 불량을 차단하는 실무적 효율성을 입증합니다.

---

## 4. 불량 원인 분석 (Root Cause Analysis)

모델의 변수 중요도(Feature Importance) 분석을 통해 공정 개선을 위한 핵심 타겟을 도출하였습니다.

1. **Sensor 59 (Primary Cause):** 불량 발생 시 수치 변동성(Variance)이 가장 크게 나타남. 공정 불안정성의 핵심 지표.
2. **Sensor 103 (Secondary Cause):** 데이터 분포가 상향 편향(Drift)될 때 불량 확률 급증. 장비 파라미터 이탈 의심.
3. **Sensor 33 (Tertiary Cause):** 통계적 상관관계가 매우 견고하며 타 센서와의 결합 시 불량 징후 증폭.

---

## 5. 결론 및 제언 (Conclusion)

1. **실무 적용성:** 본 모델은 Threshold 0.23 설정 시 최적의 탐지 성능을 보이며, 현장 도입 시 불량 유출 사고를 80% 이상 예방할 수 있을 것으로 기대됨.
2. **향후 과제:** 현재 선정된 Top 3 센서(59, 103, 33)를 중심으로 실시간 불량 감지 시스템(FDC)을 구축하고, 센서 간 상호작용 변수를 추가 도입하여 정밀도(Precision)를 점진적으로 개선할 계획임.
